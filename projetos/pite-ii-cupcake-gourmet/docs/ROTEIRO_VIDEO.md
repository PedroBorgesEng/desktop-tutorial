# Roteiro de demonstração narrada — duração aproximada de 5 minutos

> A gravação e a voz devem ser feitas pelo estudante. Este arquivo é apenas um roteiro, não um vídeo realizado.

**00:00–00:35 — Introdução.** Apresentar curso, disciplina, situação-problema 2, objetivo de criar a loja virtual de cupcakes gourmet e breve referência à continuidade do PITE I.

**00:35–01:30 — Interface e catálogo.** Mostrar landing page, filtros de categoria, busca, cards dos produtos e adaptação mobile.

**01:30–02:45 — Jornada do cliente.** Criar conta fictícia, fazer login, adicionar produtos, mudar quantidades no carrinho, cadastrar endereço e emitir pedido demonstrativo; reforçar que o pagamento é simulado.

**02:45–03:35 — Pedidos e regras.** Apresentar histórico, status, cálculo de frete e cancelamento; explicar que cancelar antes do envio recompõe estoque.

**04:20–05:10 — Código e testes.** Mostrar `models.py`, `services.py`, `main.py`, `static/app.js`, executar Pytest e Node Test Runner; apontar 14 testes Python e 5 testes JS aprovados, com captura de terminal; mencionar limitações de testes E2E conforme relatório.

**05:10–05:25 — Encerramento.** Agradecer, exibir a documentação e o caminho GitHub onde os arquivos foram versionados. Não expor senha de administrador no vídeo.
